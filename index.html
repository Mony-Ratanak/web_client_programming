Accessing Your cPanel Dashboard

⭐ The Most Important Rule in Web Hosting

📦 Your Hosting Server
🔒
/etc/ — Private config files (NOT visible)
🔒
/logs/ — Server logs (NOT visible)
🌐
/htdocs/  ←  PUBLIC FOLDER
📄 index.html → yoursite.epizy.com/index.html ✅ VISIBLE
📂 wp-content/ → yoursite.epizy.com/wp-content/ ✅ VISIBLE
📄 style.css → yoursite.epizy.com/style.css ✅ VISIBLE
🔒
/tmp/ — Temporary files (NOT visible)
✅ Golden Rule: Only files placed inside the htdocs folder (sometimes called public_html) are accessible to visitors on the internet. Files outside this folder are completely private. This is a core security feature of all web servers.

What is FTP? Why Not Just Use the File Manager?

FTP (File Transfer Protocol) is a dedicated connection between your computer and the server, designed specifically for moving files efficiently. The browser-based File Manager works but has serious limitations for large websites.

🌐 Browser File Manager
  • Uploads go through your web browser
  • Can time out for files over 50 MB
  • Cannot upload entire folders at once
  • Slow — extra overhead from browser
  • Clunky for managing many files
  • Good for: quick single-file edits
⚡ FTP with FileZilla
  • Direct protocol connection to server
  • Handles large WordPress .wpress files
  • Drag and drop entire folders
  • Fast — optimised for file transfers
  • See both local and server files simultaneously
  • Industry standard used by all developers

The FileZilla Interface — Left Side vs Right Side

This is the most important thing to understand before opening FileZilla. The window is split into two halves:

💻 LEFT panel = YOUR computer

Navigate to find the file on your laptop. Your Documents, Desktop, Downloads folders all appear here.

🌐 RIGHT panel = WEB SERVER

Your live hosting account. Navigate to htdocs folder. Anything you drop here goes live on the internet.

Making the Connection & First Upload

⚠ FTP Blocked by Campus Firewall? Read This First!

Campus networks often block Port 21 (the FTP port) for security. If FileZilla shows "Connection timed out" or "ECONNREFUSED", this is why. Here are your options:

Option 1 (Best): Use your phone as a hotspot

Turn on your phone's mobile hotspot. Connect your laptop to it. Then try FileZilla again. Mobile networks usually don't block Port 21.

Option 2: Use a free VPN

Install a free VPN app (Windscribe, ProtonVPN). Connect to any server. Then try FileZilla again — the VPN tunnels through the firewall.

Option 3 (Fallback): Use cPanel File Manager

If FTP won't work at all: go back to cPanel → File Manager → navigate to htdocs → click the Upload button in the toolbar to upload files directly in the browser. Slower but always works.

0 / 4 steps

Clean the Server — Prepare for WordPress

Next week you'll import your entire WordPress site into htdocs. But if index.html is already there, WordPress won't install cleanly. You need to delete the test file now.

🧹 Why delete it? When All-in-One WP Migration restores your site, it installs WordPress files into htdocs. If index.html already exists there, it will conflict with WordPress's own index.php file. Starting with an empty htdocs = clean, conflict-free WordPress installation.
