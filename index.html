Key Concept

Content vs Presentation — Why Themes are Powerful

Before installing a theme, understand the most important idea in WordPress: Content and Presentation are completely separated.

Weeks 1–4 · HTML/CSS Files
  • Layout lived inside your HTML/CSS files
  • Change the layout → you had to rewrite HTML
  • Change the font → update every CSS file
  • Content and design were mixed together
→
WordPress · Theme System
  • All content (posts, pages) stored in the database
  • Presentation (layout, fonts) controlled by the theme
  • Swap themes in 1 click → all content stays intact
  • Change the global font in one single field
📚
The Book Analogy: The database is the book's written text. The theme is the cover design and print layout. You can rebind the same book in a completely new cover — without changing a single word inside.
🎯 Today's proof: We will install the Astra theme. The entire look of the site will change instantly — but every post, page, image, and category from Week 9 will remain exactly where it was.
Phase 1 · 30 min

Install & Activate the Astra Theme

🎨 What is a WordPress Theme?

A theme is a collection of PHP templates, CSS stylesheets, and JavaScript files that control how your entire website looks — fonts, colours, spacing, header style, footer layout, everything visual. The free WordPress Theme Repository has over 10,000 themes you can install in one click.

★ Recommended
Astra
Most popular, fastest loading, best Gutenberg support. Used by 1.5 million+ websites. Use this today.
Also Good
GeneratePress
Extremely lightweight and developer-friendly. Also compatible with Gutenberg.
Also Good
Kadence
Modern design tools, great free version, excellent block editor compatibility.
Avoid
Divi / Elementor
Page-builder themes. They conflict with native Gutenberg blocks used in this course.
  1. Go to Appearance → Themes
    In the left-hand WordPress menu, hover over Appearance. A sub-menu slides out — click Themes.
    Appearance → Themes
    You will see the currently installed themes as thumbnail cards. Your active theme (probably Twenty Twenty-Four) has a blue Active label in the top-left corner.
  2. Click "Add New Theme" at the top of the page
    Click the large Add New Theme button (or the dashed + card on some WordPress versions).
    You are now browsing the WordPress.org Theme Repository — thousands of free themes, all reviewed and safe to install.
  3. ★ KEY STEP Search for "Astra" and install it
    1. Find the Search themes… input box in the top-right area
    2. Type: Astra
    3. The Astra theme card appears — look for the blue/teal icon and "by Brainstorm Force"
    4. Hover your mouse over the Astra card — two buttons appear: Install and Preview
    5. Click Install
    6. Wait about 10–15 seconds while WordPress downloads and installs Astra
    💡 The Install button downloads the theme files to your server. The theme is NOT active yet — it is just installed.
  4. ★ KEY STEP Click "Activate" to apply Astra to your site
    After installation, the Install button changes to two new buttons: Activate and Live Preview.
    1. Click Activate (not Live Preview)
    2. WordPress applies Astra to your site immediately
    3. You are redirected back to the Themes page — Astra now has the Active label
    ✅ Astra is now active! Your site is using it right now.
  5. Visit your site to see the change
    1. In the black admin bar at the top, hover over the house icon (your site name)
    2. Click Visit Site
    3. Your entire website now has a clean, modern look — completely different from before
    ✅ All your posts, pages, images, and categories from Week 9 are still there. Only the visual presentation has changed. This is the power of separating content from presentation!
Phase 2 · 30 min

Theme Customizer — Typography & Colours

Part 1 of 2
⚙️ What is the Theme Customizer?

The Customizer is a live-preview editor that controls global CSS — styles that apply to every single page of your site at once. Think of it as your site's global stylesheet, but with a visual interface.

Customizer controls:
  • Site-wide font (typography)
  • Brand colour (buttons, links, accents)
  • Logo and site identity
  • Header and footer layout
Block Editor controls:
  • Individual page content
  • Block-specific styles
  • Per-page layouts
  • Images and text inside pages
  1. Open the Theme Customizer
    Return to the Dashboard, then navigate to:
    Appearance → Customize
    The Customizer opens. You will see:
    • A left sidebar with all the settings panels
    • A live preview of your site on the right — it updates as you make changes
    • A Publish button at the top-left — you must click this to save changes
  2. ★ KEY STEP Change the global typography (font)
    This changes the font for your entire website in one setting.
    1. In the left sidebar, click Global to expand it
    2. Click Typography
    3. Find the Base Font dropdown
    4. Click the dropdown and try one of these popular Google Fonts:
      Roboto — clean, modern, great for tech Montserrat — bold, professional look Open Sans — friendly, very readable
    5. Watch the live preview on the right update instantly — no page reload needed
    💡 This is the power of the Customizer — the live preview means you can try different fonts and see the result immediately, before committing to it.
  3. Adjust font sizes (optional but recommended)
    While still in Typography, scroll down to find:
    • Headings Font Size — controls all H1, H2, H3 sizes globally
    • Body Font Size — controls paragraph text size (16px is standard)
    💡 Leave these at the default values if you are happy with them. You can always come back to the Customizer to adjust later.
  4. ★ KEY STEP Change the brand colour (Theme Color)
    The Theme Color controls buttons, links, and accent colours across the entire site.
    1. In the left sidebar, click the back arrow ← to return to the main Customizer menu
    2. Click Global again → then click Colors
    3. Find Theme Color (sometimes called Accent Color)
    4. Click the colour swatch — a colour picker appears
    5. Choose a colour that fits a tech news site. Some ideas:
      #1f7a8cTeal #2e75b6Blue #1f3864Navy #6b2fa0Purple #c00000Red
      Or type your own hex code directly in the # field.
    6. Watch the preview update — buttons and links on the right side change colour
  5. ★ SAVE Click Publish to save your changes
    IMPORTANT: Changes in the Customizer are NOT saved automatically. You must click the blue Publish button at the very top of the left sidebar.
    ⚠️ If you close the Customizer without clicking Publish, ALL your changes will be lost! Always Publish before leaving.
    ✅ After Publish — the site now uses your custom font and brand colour globally.

Customizer — Site Identity & Logo

Part 2 of 2

The Site Identity section controls the logo, site title, tagline, and the small browser tab icon (favicon). A proper logo replaces the plain text site name for a more professional look.

💡 No logo yet? Create a free simple logo right now at canva.com — search for "logo" templates, add your site name, and download as PNG with transparent background. Takes less than 5 minutes.
  1. Navigate to Site Identity in the Customizer
    If you already closed the Customizer, go to Appearance → Customize again. In the left sidebar, click Site Identity.
    You will see fields for: Logo · Site Title · Tagline · Site Icon (favicon).
  2. ★ KEY STEP Upload your logo
    1. Click the Select logo button
    2. The Media Library popup opens — click Upload Files tab
    3. Click Select Files and choose your logo PNG from your computer
    4. WordPress uploads the logo and adds it to your Media Library
    5. A crop dialog may appear. Click Skip Cropping to keep the original dimensions
    6. Click the blue Select button to confirm the logo
    💡 Always use PNG format with a transparent background for logos — it means the logo blends into any header colour without a white rectangle around it.
  3. Control how the site title appears
    Below the logo, find the "Display Site Title and Tagline" checkbox.
    If your logo has your site name in it:
    Uncheck "Display Site Title" to hide the plain text name
    Prevents duplication — logo text + plain text would look odd
    OR
    If your logo is an icon / symbol only:
    Keep "Display Site Title" checked
    The site name appears as text next to the icon logo
  4. Update the Site Tagline
    Find the Tagline text field. Delete the default text and type something descriptive:
    "Your #1 Source for Tech News"
    The tagline often appears under the logo in the header and in browser tab titles.
  5. ★ SAVE Click Publish → Exit the Customizer
    1. Click the blue Publish button at the top of the left sidebar
    2. Wait for the saving animation to complete
    3. Click the X button in the very top-left to exit and return to the Dashboard
    ✅ Your site now has a custom font, brand colour, and logo applied globally.

Homepage Layout — The Cover Block (Hero Section)

Part 1 of 2
Welcome to TechWorld
Read Our Blog
← This is the Cover Block: full-width background image + H1 headline + Button overlay
CSS
What you did in Week 3–4:
background-image: url(...)
background: rgba(0,0,0,0.5)
width: 100%; position: relative
= same as →
WP
What the Cover Block does:
Background image → set via Upload button
Dark overlay → Opacity slider in sidebar
Full width → Align button in toolbar
  1. Open the Home page for editing
    Pages → All Pages → Edit (Home)
    The Gutenberg block editor opens for the Home page.
  2. Delete ALL existing content blocks
    The Home page currently has the plain welcome text you wrote in Week 9. We are rebuilding it from scratch with a proper layout.
    1. Click on the first block in the editor to select it
    2. Press Ctrl+A to select ALL blocks on the page
    3. Press Delete or Backspace to remove them
    Alternative method: click each block → click the 3-dot menu (⋮) at the right of the toolbar → click Remove Block.
    💡 The editor should now show a single empty block with the "Type / to choose a block" placeholder text.
  3. ★ KEY STEP Add the Cover block using the slash command
    The fastest way to add any block is the slash command:
    1. Click the empty editor area
    2. Type / (forward slash) — a block search popup appears
    3. Type cover
    4. The Cover block option appears — click it or press Enter
    🧱 Gutenberg Block Shortcut
    Press / on any empty line to search and insert any block instantly. This is the fastest way to build pages in Gutenberg.
  4. ★ KEY STEP Upload a background image for the Cover block
    The Cover block appears with options to add a background.
    1. Click Upload inside the Cover block
    2. Choose a wide, landscape-format image from your computer (a city skyline, tech background, or any professional-looking wide photo).
      Tip: images from unsplash.com in landscape format work perfectly.
    3. The image becomes the background of the Cover block
    💡 Alternatively, click Media Library if you already have a suitable landscape image uploaded from Week 9.
  5. Add the H1 headline inside the Cover block
    The Cover block now has a dark overlay with a cursor inside it.
    1. Click inside the Cover block — a cursor appears
    2. Type / → type heading → press Enter
    3. Type your headline: Welcome to TechWorld
    4. Look at the toolbar above the heading block. Find the H2 label → click it → change to H1 (your main page headline should always be H1)
    💡 H1 is the most important heading on the page for SEO. Only use H1 once per page — your hero headline is the perfect place.
  6. Add a Buttons block below the H1 headline
    1. Click after the H1 headline text → press Enter to create a new line inside the Cover
    2. Type / → type buttons → press Enter
    3. A button block appears — click the button text and type: Read Our Blog
    4. Click the link icon (🔗) in the button's toolbar to add a URL. Type: http://localhost/mywebsite/ (this links to the homepage — WordPress will show the blog if no static page was set, or you can link to any of your category pages)
    5. Press Enter to confirm the link
  7. ★ KEY STEP Set the Cover block to "Full Width"
    By default, the Cover block is constrained to the page content width (~800px). Full Width stretches it to 100% of the browser window — essential for a professional hero section.
    1. Click on the outer edge of the Cover block to select the whole block (not just the text inside it)
    2. Look at the toolbar that appears directly above the Cover block
    3. Find the Align icon — it looks like horizontal lines with arrows, or sometimes shows a width symbol
    4. Click it — a dropdown appears with: None · Wide Width · Full Width
    5. Select Full Width
    6. The Cover block immediately stretches to fill the entire browser width
    CSS Connection:
    /* What Full Width does behind the scenes */
    .wp-block-cover.alignfull {
    width: 100vw;
    margin-left: calc(-50vw + 50%);
    }
    💡 If you cannot see the Align icon, make sure you selected the outer Cover block — not a heading or button block inside it. Click on the very edge of the dark background area.
  8. ★ KEY STEP Adjust the overlay opacity so text is readable
    The dark overlay between the background image and the text controls contrast. Without enough overlay, white text on a light photo is unreadable.
    Opacity 10%
    Text barely readable
    Opacity 40%
    Starting to work
    Opacity 60%
    ✅ Good balance
    Opacity 85%
    Too dark — barely see image
    How to adjust opacity:
    1. Click the Cover block to select it
    2. Look at the right sidebar panel (not the toolbar above the block)
    3. Find the Overlay section — it has an opacity slider
    4. Drag the slider until the text reads clearly. A value between 40–60 usually works well
    CSS Connection:
    /* This is the same as what you used in Week 3 */
    .cover-overlay {
    background: rgba(0, 0, 0, 0.50); /* 50 = opacity 50 */
    }
  9. Click Update to save and preview the hero section
    1. Click the blue Update button in the top-right corner
    2. Click View Page in the link that appears
    3. You should see a full-width hero banner with your background image, dark overlay, headline, and button
    ✅ The hero section is complete! Your homepage now has a professional full-width banner — just like real websites you see every day.

WP
Columns Block:
Select 33/33/33 layout
Click + inside each column
Add Image · H3 · Paragraph
  1. Add a new block BELOW the Cover block
    In the block editor, scroll down past the Cover block. Click on the area below it — a new empty block line appears.
    💡 If clicking below doesn't work, click the very bottom edge of the Cover block and press the ↓ arrow key to move the cursor below it.
  2. ★ KEY STEP Add the Columns block and choose 33/33/33 layout
    1. Type / → type columns → press Enter
    2. A visual layout chooser appears showing different column layouts:
      50/50
      33/33/33 ← Select this
      25/50/25
      70/30
    3. Click the 33 / 33 / 33 option — three equal columns appear
    💡 33/33/33 = three columns each taking exactly 1/3 of the width. This is identical to CSS flex: 1 or width: 33.33% — Gutenberg just makes it visual.
  3. ★ COLUMN 1 Build the first column: Image + H3 + Paragraph
    Click inside Column 1 (the leftmost column).
    1. Add an Image: Type / → image → Enter. Click Media Library → select one of your uploaded images.
    2. Add a Heading: Click below the image → type / → heading → Enter. Type a feature name, e.g. Fast Performance. Change the heading level to H3 in the toolbar (H3 because H1 is already used in the Cover block — heading hierarchy matters!).
    3. Add a Paragraph: Click below the heading → type / → paragraph → Enter. Write 1–2 sentences describing this feature, e.g.: "Our site is optimised for speed, delivering content in under one second."
    💡 Heading hierarchy: H1 (once per page) → H2 (main sections) → H3 (sub-sections). Never skip levels — this affects accessibility and Google search ranking.
  4. ★ COLUMN 2 Build the second column: Image + H3 + Paragraph
    Click inside Column 2 (the middle column).
    1. Add an Image block → choose a different image from Column 1
    2. Add a Heading (H3) → type: Latest Tech News
    3. Add a Paragraph → write 1–2 sentences: "We publish fresh tech news, reviews, and analysis every single day."
  5. ★ COLUMN 3 Build the third column: Image + H3 + Paragraph
    Click inside Column 3 (the rightmost column).
    1. Add an Image block → choose a different image again
    2. Add a Heading (H3) → type: Expert Reviews
    3. Add a Paragraph → write 1–2 sentences: "All reviews are written by experienced professionals in the technology field."
  6. Add padding around the Columns block
    The columns might sit too close to the hero banner. Add some breathing room:
    1. Click the outer Columns block wrapper to select it (not a single column — the full three-column group)
    2. In the right sidebar, look for the Dimensions section
    3. Find Padding — click the icon and add padding to the top and bottom (e.g. 40px top and bottom)
    💡 This is the same as CSS padding: 40px 0; — Gutenberg just has a visual control for it.
  7. Click Update → Preview the full homepage
    1. Click the blue Update button
    2. Click View Page
    3. Your homepage should now show: Full-width hero banner → 3-column features grid
    ✅ Your homepage now has a professional modern layout! This looks like a real website — not just a plain blog.
Phase 4 · 15 min

Refine & Final Audit

Polish the homepage and verify everything works before calling it complete. A well-built page must look good, work correctly, and be responsive.

  • Balance the three column images
    All three column images should be roughly the same visual height. If one image is portrait and two are landscape, the columns will look uneven. Swap any mismatched image for one with a similar aspect ratio to the others.
  • Check heading hierarchy is correct
    Verify: H1 appears once in the Cover block headline → H3 appears in each column. Never skip from H1 directly to H3 without H2 — this breaks accessibility and hurts Google ranking.
  • Test the "Read Our Blog" button link
    Click the button on the live site. It should navigate to your blog/posts page or category page. If it opens a 404 error, go back and fix the button URL.
  • Check the hero overlay — text must be readable
    On the live site, view the hero section. The headline and button must be clearly legible against the background image. If text is hard to read, go back to the editor → select the Cover block → increase the opacity slider in the right sidebar.
  • Test responsiveness on a narrow window
    Drag your browser window narrower to simulate a mobile screen. Gutenberg's Columns block automatically stacks vertically on small screens — you should see one column per row, not three crushed columns side by side.
    💡 This is responsive design by default — Gutenberg handles the CSS @media queries automatically. In Weeks 3–4 you had to write these manually!
  • Preview as a logged-out visitor (incognito window)
    Open a private / incognito browser window and type your site URL. The black admin bar must NOT appear — regular visitors never see it. The site should look exactly like a real public website.
  • Verify the Astra theme is still active
    Go to Appearance → Themes. Astra should have the Active label. Your custom font and brand colour should be visible.
