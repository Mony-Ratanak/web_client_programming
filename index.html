Key Concept — Understand This Before Starting

The 5 WordPress User Roles

WordPress has a built-in role-based access control system. Every user is assigned exactly one role, which determines what they can see and do in the admin panel.

🔐 The Principle of Least Privilege Only give users the minimum permissions they need to do their job. When building a site for a client, give them Editor access — never Admin. If they accidentally delete a plugin, the whole site could break. You maintain Admin control.

Why You Can't Just Copy the Files

A WordPress site consists of two completely separate parts. You need both to have a working backup. Many beginners only back up one and wonder why their site doesn't work on another computer.

📁

FILES — The htdocs Folder

  • WordPress core PHP files
  • Themes (Astra, child theme)
  • Plugins (Elementor, WPForms...)
  • Uploaded images & media
📂 htdocs/your-site/
❌ If you only copy this: site structure exists but ALL content is gone (no posts, no pages, no settings)
+
🗃

DATABASE — MySQL

  • All post and page content (text)
  • Comments and user accounts
  • Plugin settings & options
  • Navigation menus & widgets
🗄 phpMyAdmin → your_db
❌ If you only export this: content exists but no theme, no images — blank white page
✅
The Solution: All-in-One WP Migration

This plugin combines FILES + DATABASE into a single .wpress file. One file = your entire website, ready to restore or deploy anywhere.

📝

+
🔌

+
🖼
Media

All uploaded images & files

→
📦
.wpress

One file = entire site!

UpdraftPlus — The Industry Standard for Live Sites

All-in-One WP Migration is great for migrating a site once. But for a live production website that's being updated daily, you need automatic scheduled backups — that's where UpdraftPlus comes in.

All-in-One WP Migration
  • ✓ Manual one-time export
  • ✓ Single .wpress file
  • ✓ Perfect for migration
  • ✓ Used in this lab + Week 14
  • ✗ No automatic scheduling
  • ✗ No cloud storage in free version
Use when: Moving or deploying a site

Real-World Disaster Scenarios — Why Off-Site Backup Is Critical

🔥
Server fire / hardware failure

The hosting server's hard drive dies. Without an offsite backup, the site is gone forever. With Google Drive backup: restore in 10 minutes.

🔓
Hacker deletes the database

Ransomware or a malicious actor deletes all content. Your backups saved to the same server are also gone. Cloud backup = the only survivor.

🔌
Bad plugin update crashes the site

A plugin update introduces a fatal PHP error. The site shows a white screen of death. Restore from yesterday's backup and roll back the update.

🤦
Human error — accidentally deleted

You accidentally delete 200 blog posts while trying to bulk-edit. "Ctrl+Z" doesn't work in WordPress. Yesterday's backup restores them all.

Quick Reference — Session 3 Summary

👑

5 User Roles

Admin → Editor → Author → Contributor → Subscriber. Each role controls a specific level of access.

🔐

Least Privilege

Give clients Editor, not Admin. Fewer permissions = fewer accidents. You maintain full control.

📁

Files + Database

WordPress = Files (themes/plugins/images) + Database (all content). You need BOTH for a complete backup.

🔄

All-in-One Migration

Install, Export → File, Download. Creates a .wpress file = your entire site in one archive.

📦

.wpress File

Store on USB + Google Drive. This exact file will be used in Week 14 to deploy to a live server.

⏰

UpdraftPlus

For live production sites. Schedules automatic weekly backups to Google Drive or Dropbox.
