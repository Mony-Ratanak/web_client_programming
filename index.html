Key Concept

Theme vs Plugin — The Critical Difference

Before installing anything, understand the most important distinction in WordPress:

🎨 THEME — Controls How the Site LOOKS
  • Changes fonts, colours, layout, spacing
  • Controls header, footer, and sidebar structure
  • Only ONE active theme at a time
  • Session 1: We installed Astra
+
🔌 PLUGIN — Controls What the Site DOES
  • Adds new features and functionality
  • Contact forms, security, SEO, e-commerce
  • You can have MANY plugins active at once
  • Today: WPForms + Security plugin
⚠️ CRITICAL SECURITY RULE — Read Before Installing Anything
❌ NEVER do this:
  • Download plugins from random Google search results
  • Install "nulled" or "cracked" premium plugins
  • Get plugin ZIPs from Telegram groups
  • Download from any site other than wordpress.org
Pirated plugins almost always contain hidden malware that silently steals your admin password and sends it to a hacker's server.
✅ ALWAYS do this:
  • Install ONLY from the WordPress Dashboard
  • Use Plugins → Add New (official repository)
  • All 60,000+ plugins there are reviewed by WordPress
  • Check: 5-star rating + last updated recently
The official repository is free, safe, and always up to date. Every plugin in this session will be installed this way.

Install & Activate WPForms

🔌 What is WPForms?

WPForms is the most popular WordPress form builder plugin with 6 million+ active installations. It creates contact forms with drag-and-drop — no HTML, CSS, JavaScript, or PHP needed. It handles everything your Week 6 form validation code did, plus PHP email sending, automatically.

Week 6 — You wrote ~50 lines of code
// HTML form + CSS + JS validation
<form id="contact">
  <input type="email" id="email">
  ...
</form>
function validateForm() {
  // 40+ lines of JS validation...
  // No PHP email sending!
}
→ WPForms replaces all this →
Today — Zero code, more features
  • HTML form structure ✅ auto
  • CSS styling ✅ auto
  • JS validation ✅ auto
  • PHP email sending ✅ auto
  • Database storage ✅ auto
  • Spam protection ✅ auto
  1. Go to Plugins → Add New Plugin
    In the left WordPress menu, hover over Plugins → click Add New Plugin.
    Plugins→ Add New Plugin
    You are now browsing the WordPress.org Plugin Repository — 60,000+ free, reviewed plugins. Notice the download counts in the millions. Click the "Popular" tab to explore.
  2. Search for "WPForms" in the search bar
    Find the search input in the top-right area of the page. Type: WPForms
    The WPForms Lite plugin appears — look for:
    • Blue "WP" logo icon
    • "By WPForms" under the title
    • 6,000,000+ active installations

    ⚠️ Make sure you click the correct plugin — "WPForms" not "WP Forms" or similar fake plugins.

    2. An Install Now button appears

    5. A progress bar and then a checkmark appears when done

  4. ★ KEY STEP Click "Activate"

    1. Click Activate (not "Live Preview")

  5. Notice the new WPForms menu item in the sidebar

Build the Contact Form — Part 1: Create & Name the Form

Part 1 of 2

WPForms has a visual drag-and-drop form builder. You will create a form, use a pre-built template, and explore the existing fields.

  1. Open WPForms → click "Add New"
    Click WPForms in the left menu → click Add New.
    WPForms→ Add New
    The WPForms builder page opens. You will see a field for the form name and template cards below it.
  2. Name your form "Main Contact Form"
    At the top of the page, find the "Name Your Form" field.
    1. Click inside the name field
    2. Delete any existing placeholder text
    3. Type exactly: Main Contact Form
    💡 The name is for your own reference inside the Dashboard — visitors never see it. Choose a name that describes the form's purpose.
  3. ★ KEY STEP Select the "Simple Contact Form" template
    Below the name field, you see template cards. Find Simple Contact Form:
    1. Look for the card labelled "Simple Contact Form"
    2. Hover over it — a Use Template button appears
    3. Click Use Template
    The WPForms drag-and-drop builder opens. You will see:
    • Left panel: Available field types (Add Fields)
    • Right/centre: The form preview with pre-built fields
    • Top toolbar: Save button and settings tabs
    ✅ The template already created 3 fields for you: Name, Email, and Comment/Message.
  4. Explore the 3 pre-built fields
    Look at the form preview on the right side. You should see these fields:
    Name
    <input type="text">
    Free text — Name field, accepts anything
    Email
    <input type="email">
    Auto-validates format — must have @ and domain
    Comment / Message
    <textarea>
    Multi-line text — for the message body
    💡 Try clicking on any field in the preview — a settings panel opens on the left showing options like Label, Required toggle, Placeholder text, etc.
  5. ★ SAVE Click Save to save the form
    Find the orange Save button in the top-right corner of the builder.
    1. Click Save
    2. A small "Saved" confirmation appears briefly
    ⚠️ Always save before leaving the builder — unsaved changes are lost if you close the tab!
Phase 2 · Continued

Build the Contact Form — Part 2: Add Custom Dropdown Field

Part 2 of 2
🔽 Why add a Dropdown (Subject) field?

A dropdown forces users to choose from a pre-set list, which means: no typos, consistent data, easier to filter. In HTML Week 2, you wrote <select><option> manually. In WPForms, you drag it in and type the options — no code.

  1. Re-open the form builder (if you closed it)
    If you left the builder, go to:
    WPForms→ All Forms→ Edit (Main Contact Form)
  2. Find the "Dropdown" field in the left panel
    Look at the Add Fields panel on the left side of the builder. It shows categories of field types: Standard Fields, Fancy Fields, Payment Fields, etc.
    1. Under Standard Fields, find the Dropdown field
    2. It has a downward arrow icon (▾)
    💡 All the field types listed on the left are different HTML input types you already know. WPForms just provides a visual interface to add them without writing code.
  3. ★ KEY STEP Drag the Dropdown field into the form
    Position the dropdown BELOW the Email field:
    1. Click and hold the Dropdown field in the left panel
    2. Drag it to the right side — over the space between the Email and Comment/Message fields
    3. A blue line appears showing where it will be inserted
    4. Release the mouse to drop it there
    The Dropdown field is now added to your form. A settings panel automatically opens on the left.
    💡 If drag-and-drop doesn't work, try just clicking the Dropdown field in the left panel — WPForms will add it to the bottom of the form automatically.
  4. ★ KEY STEP Change the Label to "Subject"
    Click on the new Dropdown field in the form preview to open its settings in the left panel. Find the Label field:
    1. Find the Label text input in the settings panel
    2. Delete the current text (it says "Dropdown")
    3. Type: Subject
    4. Watch the field label update in the preview automatically
  5. ★ KEY STEP Set the dropdown Choices to 3 options
    In the same settings panel, scroll down to find the Choices section. This is where you define the options in the dropdown:
    1. You will see existing placeholder choices like "First Choice", "Second Choice"
    2. Click on First Choice → delete the text → type: General Inquiry
    3. Click on Second Choice → delete → type: Support
    4. Click on Third Choice → delete → type: Sales
    5. If there are extra choices, click the red minus (−) button next to them to delete
    Your dropdown will look like this:
    — Select a subject —
    General Inquiry
    Support
    Sales
    💡 In HTML this would be: <select><option>General Inquiry</option>...</select> WPForms generates this for you.
  6. ★ KEY STEP Toggle the "Required" switch ON
    Scroll down in the Dropdown field settings panel to find the Required toggle switch.
    1. Find the toggle labelled Required
    2. Click it so it turns blue/green (ON)
    3. A red asterisk (*) appears next to the Subject label in the preview
    Required OFF
    Subject (no asterisk)
    User can skip this field and still submit
    →
    Required ON ✅
    Subject *
    Form WILL NOT submit without this field
  7. ★ SAVE Click Save → then click X to exit the builder
    1. Click the orange Save button (top-right)
    2. Wait for the "Saved" confirmation
    3. Click the X button or the back arrow to exit the builder
    ✅ Your form now has 4 fields: Name · Email · Subject (dropdown, required) · Message.
    The form exists in the database but is not yet on any page.
Phase 3 · 30 min

Shortcodes & Embedding — Put the Form on the Contact Page

Part 1 of 2
🧩 What is a WordPress Shortcode?

A shortcode is a small text tag inside square brackets that WordPress replaces with complex PHP output when loading a page.

You type in the editor:
[wpforms id="1" title="false"]
→
WordPress calls WPForms PHP function:
wpforms_get_form(1)
→
Visitor sees on the page:
A fully styled, working contact form with all your fields!
💡 Shortcodes work on any page or post. You could put the same contact form on 10 different pages using the same one line of text.
  1. Go to WPForms → All Forms to find your shortcode
    WPForms→ All Forms
    You will see your Main Contact Form listed in a table. The table has several columns including: Name · Entries · Created · Shortcode.
  2. ★ KEY STEP Copy the Shortcode
    Find the Shortcode column next to "Main Contact Form".
    1. You will see a code like: [wpforms id="1" title="false"]
    2. Click on the shortcode text — it may auto-copy, or select all and press Ctrl+C
    3. The shortcode is now in your clipboard
    💡 The id="1" is the unique ID of your form in the database. Every form gets a different ID number.
  3. Open the Contact page for editing
    Pages→ All Pages→ Edit (Contact)
    The Gutenberg block editor opens for your Contact page.
  4. Remove any existing placeholder text on the Contact page
    If you added placeholder text in Week 9 (like "Use the form below to get in touch"), select it and delete it — or keep it above where you will add the shortcode block.
  5. ★ KEY STEP Add a Shortcode block
    In the Gutenberg editor, you need to add a Shortcode block (not a Paragraph block):
    1. Click an empty area in the editor to place the cursor
    2. Click the + (Add Block) button or type /
    3. In the search box, type: shortcode
    4. Click the Shortcode block — it has a curly bracket icon { }
    5. A text input box appears labelled "Enter shortcode here…"
    💡 The Shortcode block is different from a Paragraph block. A Paragraph block displays text. A Shortcode block executes PHP code and renders its output.
  6. ★ KEY STEP Paste your shortcode into the block
    1. Click inside the Shortcode block text area
    2. Press Ctrl+V (Windows) or Cmd+V (Mac) to paste
    3. You should see: [wpforms id="1" title="false"]
    💡 In the Gutenberg editor you may not see a live preview of the form — that is normal. The form only renders when a visitor actually views the page.
  7. Click Update to save the Contact page
    1. Click the blue Update button in the top-right corner
    2. Wait for "Updated" confirmation
    3. Click View Page to see the live result
    ✅ Your Contact page should now display a fully styled, working contact form! You should see the Name, Email, Subject dropdown, and Message fields.
Phase 3 · Continued

Test the Contact Form — Validation Scenarios

Part 2 of 2

A good form must reject invalid or incomplete submissions. Test every scenario below on the live Contact page before moving on.

  1. TEST 1 Submit with ALL fields empty
    On the live Contact page, click Submit without filling in anything.
    Expected result:
    Red error messages appear under every required field. The form does NOT submit.
    💡 This is the same "required field" behaviour you implemented with JavaScript in Week 6. WPForms does this automatically for all Required fields.
  2. TEST 2 Enter a broken email address
    Fill in the Name field, then type an invalid email like hello or hello@ (without a full domain). Leave Subject and Message empty.
    Expected result on the Email field:
    "Please enter a valid email address."
    💡 WPForms validates the email format using the same regex you used in Week 6: must have text + @ + domain + .extension.
  3. TEST 3 Leave the Subject dropdown unselected
    Fill in Name and Email correctly. Leave the Subject dropdown on the blank "— Select —" option. Fill in a message. Click Submit.
    Expected result on the Subject field:
    A required field error appears — because you toggled Required ON in Phase 2.
  4. TEST 4 Fill in everything correctly → Submit
    Fill in all fields with valid data:
    NameYour Name
    Emailtest@example.com
    SubjectGeneral Inquiry
    MessageThis is a test message.
    Click Submit.
    Expected result:
    A green success message appears: "Thanks for contacting us! We will be in touch with you shortly."
    💡 On localhost: the email does NOT actually send to your inbox. But in a real hosted WordPress site, WPForms would email the submission to your admin address. The submission IS saved — go to WPForms → Entries to view it in the database.
  5. View the form submission in WPForms → Entries
    After a successful submission, go check the database:
    WPForms→ Entries
    You should see your test submission listed with all the field values. This is where all real form submissions are stored in the database.
    ✅ Phase 3 complete! You have a working contact form embedded on your Contact page using a shortcode.
Phase 4 · 15 min

Security — Install Limit Login Attempts Reloaded

🔴 What is a Brute-Force Attack? (The #1 WordPress Threat)

WordPress powers 43% of all websites on the internet. This makes it the biggest target for automated hacker bots.

A brute-force bot finds your /wp-admin login page and tries thousands of username + password combinations per minute: admin / 123456, admin / password, admin / admin123...

Bot finds
/wp-admin
→
Tries admin
+ 123456
→
Fails →
tries again
→
Tries 1000s
of passwords
→
Eventually
logs in!
✅ The Fix: Limit Login Attempts Reloaded automatically locks out any IP after 4 failed attempts. The bot gets blocked after 4 tries instead of 10,000.
  1. Go to Plugins → Add New Plugin
    Plugins→ Add New Plugin
  2. Search for "Limit Login Attempts Reloaded"
    Type the exact name in the search bar: Limit Login Attempts Reloaded
    Look for the correct plugin — it should show:
    • Name: Limit Login Attempts Reloaded
    • 3,000,000+ active installations
    • By: Limit Login Attempts Reloaded
    ⚠️ There are several similar plugins. Make sure the name is exactly "Limit Login Attempts Reloaded".
  3. ★ KEY STEP Install Now → Activate
    1. Click Install Now
    2. Wait for the download to complete
    3. Click Activate
    ✅ The plugin is now active! It is already working with the default settings — your login page is now protected.
  4. Go to Settings → Limit Login Attempts to review the configuration
    Settings→ Limit Login Attempts
    The plugin settings page opens. Review the default configuration:
    Allowed retries before lockout: 4 attempts
    Lockout duration: 20 minutes
    After 2 lockouts → extend to: 24 hours
    💡 The defaults are already good. A human who forgets their password will just be locked out for 20 minutes — a minor inconvenience. A bot that tries 10,000 passwords is completely stopped.
  5. Scroll down to see the Statistics / Log section
    On the settings page, scroll down to find the Statistics or Log section. This shows a log of all blocked login attempts — even on a brand new localhost site, you may eventually see entries here as bots scan the internet.
    ✅ Limit Login Attempts is now active and protecting your site. This ONE plugin dramatically reduces the risk of unauthorised access. Always install it on any live WordPress website.
