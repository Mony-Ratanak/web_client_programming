Before We Start

Gutenberg vs Elementor — When to Use Which

Both are WordPress editors. The key difference is control — Elementor gives you visual, pixel-perfect layout control that Gutenberg cannot match.

Gutenberg Block Editor

  • Built into WordPress — no installation needed
  • Best for: blog posts, simple pages, widgets
  • Blocks: paragraph, heading, image, columns
  • Limited visual layout control
  • CSS goes in Additional CSS panel
  • You used this in Weeks 9–11
Use for: Content & Blogs
VS

Elementor Page Builder

  • Plugin — install from Plugins → Add New
  • Best for: landing pages, full-site layouts
  • Drag-and-drop visual editor in real time
  • Pixel-perfect spacing, colour, typography
  • Style tab = CSS without writing code
  • Used by 12+ million websites worldwide
Use for: Visual Page Design
💡 Professional developers use BOTH: Gutenberg for writing content (posts, pages with text), Elementor for designing pages where the layout itself is the product — landing pages, homepages, about pages.

The Three Parts of the Elementor Interface

Elementor divides your screen into three key areas. Understanding each one before you start building will save you a lot of confusion.

The Most Important Concept: Section → Column → Widget

You cannot skip levels. You can't place a Widget directly on the canvas — it must go inside a Column, which must be inside a Section.

1
SECTION

The full-width row container. Click the 6-dot icon (⋮⋮) that appears at the top to select the whole section.

2
COLUMN

Lives inside a section. Click the book/page icon that appears at the top of a column to select it. One section can have 1–10 columns.

3
WIDGET

The actual content — Heading, Image, Button, Video, etc. Drag from the left panel and drop into a column. Click a widget on the canvas to edit it.

2
COLUMN 2

Second column in the same section — this gives us the two-column layout.

3
WIDGET

Image widget placed in the right column.

🚨 The #1 rule in Elementor: You cannot drag a Widget directly onto the canvas without a Section + Column first. Always: Section first → Column second → Widget third.

Quick Reference — Everything You Learned Today

⚡

Why Elementor

Visual drag-and-drop. Pixel-perfect control. No CSS needed for basic styling. Used by 12M+ websites.

🔌

Install

Plugins → Add New → search "Elementor Website Builder" → Install → Activate → Skip wizard.

🖥

Interface

Left Panel = widgets + settings. Canvas = live preview. Bottom bar = Settings, Undo, Update.

⚙

Section → Column → Widget

The strict 3-level hierarchy. Can't skip levels. Section first, column second, widget third.

🎨

Three Tabs

Content = what it is. Style = how it looks (CSS!). Advanced = spacing & box model (margin/padding).

💾

Save & Preview

Ctrl+S or green Update button to save. Eyeball icon (👁) to preview the live front-end page.
