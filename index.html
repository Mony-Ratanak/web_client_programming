Key Concept Before We Start

Section Background vs Image Widget — Know the Difference

Today's Hero section uses a Section Background Image — not an Image widget. These are completely different techniques with different results.

✅ Section Background Image

  • Set via Section → Style tab → Background
  • Image stretches to fill the entire section
  • Other widgets (Heading, Button) float on top
  • Can add a dark overlay for text readability
  • CSS: background-size: cover
  • Use for: Hero sections, full-width banners

Image Widget

  • Dragged from the left panel widget list
  • Occupies a specific column slot
  • Has a defined width — doesn't fill the section
  • Has its own alt text and link settings
  • CSS: renders as an <img> element
  • Use for: product photos, feature images

The CSS That Elementor Generates for a Section Background:

Elementor generates this CSS in a <style> tag in the page head
/* Section with background image */
.elementor-section {
    background-image: url("your-hero-image.jpg");
    background-size:     cover;    /* fills entire section */
    background-position: center center;
    min-height:          600px;    /* Layout tab → Min Height */
}
/* Background Overlay = CSS ::before pseudo-element */
.elementor-section::before {
    content:    "";
    background: rgba(0, 0, 0, 0.6); /* opacity 0.6 = 60% dark */
    position:  absolute;
    inset:     0;           /* covers the whole section */
}

Why Inner Sections? The Layout Problem Explained

You need a heading that spans the full width, above a 3-column grid. If you used a 3-column section, the heading would be stuck inside just one column. The solution is the Inner Section widget.

How Elementor's Responsive Mode Works

Elementor's responsive mode is visual @media query editing. When you switch to Mobile mode and change a setting, Elementor writes a CSS media query for you — the same concept you learned in LO3.

The Little Device Icon Next to Settings

When you're in Mobile mode, some settings show a tiny device icon (📱) next to them. Any change you make here ONLY applies to mobile — desktop and tablet are not affected.

Quick Reference — Session 2 Summary

🖼

Section Background Image

Style tab → Background → Classic → Image. Set Size to Cover. Used for full-width hero sections.

🌑

Background Overlay

Style tab → Background Overlay. Black at opacity 0.6 makes white text readable on any image.

📐

Min Height

Section → Layout tab → Height → Min Height → 600px. Stops the section from collapsing around content.

⬛

Inner Section Widget

Drag from widget panel. Creates a column grid inside a column — heading spans full width above the grid.

⭐

Icon Box Widget

Pre-styled icon + title + description. Style tab → Primary Colour changes the icon colour.

📱

Responsive Mode

Bottom toolbar device icons. Tiny 📱 next to a setting = mobile-only. Elementor writes @media queries for you.
