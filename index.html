Before We Start

The WordPress Customizer

The Customizer is your live preview control panel — you see every change in real time on the right side of the screen before you save anything. Appearance → Customize opens it.

⚙️

Dashboard Settings

The left panel holds all the controls — site title, logo, colors, layout settings.

👁

Live Preview Pane

The right panel shows your actual site updating in real time — no need to Save & Refresh.

🎨

Theme Extras (Astra)

Astra adds its own sections: Header Builder, Footer Builder, Global Typography, and more.

💡 Important: Every theme adds different sections to the Customizer. What you see in Astra will not look the same in another theme — but the core WordPress sections (Site Identity, Menus, Additional CSS) are always there.

What is a Widget?

A Widget is a block of content you can place inside a specific area of your theme — usually the Sidebar or the Footer. Since WordPress 5.8, widgets use the same Gutenberg blocks you already know.

¶
Paragraph block Plain text, bio description, address
H
Heading block Column title: "About Us", "Contact Info"
SI
Social Icons block Facebook, Twitter / X, Instagram links
≡
Navigation Menu block Show a saved menu (e.g. Footer Menu)
Img
Image block Logo, brand graphic, photo
LP
Latest Posts block Auto-updating list of recent blog posts
🔗 Connection to what you already know: The block editor inside Widgets works exactly the same as the Gutenberg editor you used to write blog posts. The "+" button, block search, and settings panel are identical. You already know how to use it!

Why Does a Site Need Two Menus?

Professional websites always separate their navigation into two distinct menus, each with a completely different purpose:

Primary Menu — Action
Home About ▾ Hardware Software Contact
  • Lives in the header — always visible
  • Drives visitors toward key actions: read, buy, contact
  • Short items, 5–7 max, clearly named
  • Purpose: discovery & conversion
vs
Footer Menu — Information
Privacy Policy · Terms of Service · Contact · Sitemap
  • Lives in the footer — out of the way
  • Provides legal & compliance links visitors expect to find
  • Visitors scroll down specifically to find these links
  • Purpose: compliance & trust
💡 The industry pattern: BBC, Apple, Amazon, and virtually every professional website uses exactly this two-menu pattern. Putting "Privacy Policy" in the main navigation would clutter it — the footer menu handles required links cleanly and where users expect them.

Key Concepts — Quick Reference

⚙️

Customizer

Live preview settings hub. Changes are visible instantly but only saved when you click Publish.

🏗

Header Builder

Astra's drag-and-drop grid for placing Logo, Menu, Button, and Search into 3 header columns.

📦

Widget Area

A named slot in your theme (Footer Area 1, 2, 3…) where you drop Gutenberg blocks to add content.

🦶

Footer Widgets

Gutenberg blocks placed inside footer areas — typically Heading + Paragraph + Social Icons + Navigation Menu.

🗺

Footer Menu

A secondary navigation menu holding legal / compliance links (Privacy Policy, Terms) — lives in the footer, out of the main nav.

⬜

Boxed Layout

Container setting that constrains page content to a max-width box, centred on the page with whitespace on both sides.

Where to Find Everything

Quick reference for where to find each feature in WordPress
Feature WordPress Path What it does
Header Builder Appearance → Customize → Header Builder Drag Logo, Menu, Button into header columns
Container Layout Appearance → Customize → Global → Container Switch between Boxed and Full Width
Global Colors Appearance → Customize → Global → Colors Change site-wide primary / accent colors
Footer Widget Areas Appearance → Widgets → Footer Widget Area 1/2/3 Add Gutenberg blocks to footer columns
Footer Menu Appearance → Menus → create new → assign Footer Menu location Secondary nav with legal links in footer
Publish (Customizer) Blue Publish button, top of Customizer panel Save ALL pending Customizer changes to the live site
