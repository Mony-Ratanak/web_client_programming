The Media Library — Upload & Alt Text

Part 1 of 2
📂 What is the Media Library?

The Media Library is WordPress's built-in file manager. Every image, PDF, or video you upload gets stored here. When you insert an image into a post or page, you pick it from this library — you do not link to files on your computer directly.

  1. Open the Media Library uploader
    In the left-hand WordPress menu, hover over Media. A sub-menu slides out — click Add New.
    Media → Add New
    You will see a large dotted upload box with the text "Drop files anywhere to upload".
  2. Bulk-upload all your downloaded images at once
    Open the wp-images folder on your Desktop. Select ALL the images at once (use Ctrl+A on Windows or Cmd+A on Mac), then drag-and-drop them into the WordPress upload box.
    ☁️
    Drop files anywhere to upload
    or
    Select Files
    A progress bar appears for each file. Wait until all images show a green checkmark before continuing.
    ✅ You should now see all your images as thumbnails in the Media Library grid.
  3. ★ KEY STEP Add Alt Text to every image
    What is Alt Text? It is a text description of an image. You used it in HTML Week 2 as the alt="" attribute. In WordPress, you add it through the Media Library.
    ♿
    Accessibility
    Screen-reader software reads the alt text aloud for blind users. Without it, they hear "image" — nothing useful.
    🔍
    SEO (Google)
    Google's image crawler cannot "see" photos. It reads alt text to understand what the image is about and rank it in Google Images.
    How to add alt text:
    1. In the Media Library grid, click on any image thumbnail
    2. The Attachment Details panel opens on the right side of the screen. You will see fields for: Title, Caption, Alt Text, Description
    3. Click the Alt Text field and type a clear description of the image.
      Good alt text examples:
      ❌ Bad: image1.jpg Filename — means nothing
      ❌ Bad: photo Too vague
      ✅ Good: Close-up of a computer CPU chip on a motherboard Descriptive, specific
      ✅ Good: Developer typing code on a laptop keyboard Describes the scene clearly
    4. WordPress saves alt text automatically as you type — no Save button needed
    5. Click the X in the top-right to close the panel, then click the next image and repeat
    💡 You must add alt text to every single image in the library before using them.
  4. Verify all images have alt text
    Go back to Media → Library (the full grid view). Click each image one by one and confirm the Alt Text field is filled in. Do not leave any image with an empty alt text.
    ✅ Every image in your library should now have a meaningful alt text description.

Setting Featured Images on All Posts

Part 2 of 2
🖼️ What is a Featured Image?

The Featured Image is the main thumbnail that represents a post. It is not the same as an image you put inside the post content — it is a separate designated "cover image" that WordPress displays in many places:

🏠
Homepage
Post card thumbnail in the blog list
📘
Facebook / Telegram
Preview image when you paste the URL in a chat
🔍
Google Search
Some themes show it in search result snippets
📩
RSS / Newsletters
Displayed in email digests and RSS readers
  1. ★ POST 1 Set featured image on your first post
    Follow these exact steps:
    1. Go to Posts → All Posts in the left menu
    2. Hover over your first post (e.g. "The Future of Quantum Computing") — links appear below the title
    3. Click Edit — the Gutenberg editor opens for that post
    4. Look at the right sidebar panel. If the sidebar is not visible, click the gear icon ⚙️ in the top-right toolbar.
    5. In the right sidebar, scroll down until you see the Featured Image panel
    6. Click "Set featured image" — the Media Library popup opens
    7. Click on one of your uploaded images to select it (a blue checkmark appears)
    8. Click the blue button in the bottom-right of the popup (it says "Set featured image")
    9. The image now appears as a preview in the Featured Image panel in the sidebar
    10. Click the blue Update button in the top-right to save the post
    Featured Image
    [ Selected image preview ]
    Set featured image · Remove featured image
    ✅ You will see the image thumbnail in the sidebar after setting it.
  2. ★ POST 2 Set featured image on your second post
    1. Go to Posts → All Posts
    2. Click Edit on your second post
    3. Right sidebar → Featured Image panel → Set featured image
    4. Choose a different image from the first post
    5. Click Update
  3. ★ POST 3 Set featured image on your third post
    1. Go to Posts → All Posts
    2. Click Edit on your third post
    3. Right sidebar → Featured Image → Set featured image
    4. Choose a different image again
    5. Click Update
  4. Verify featured images in the Posts list
    Go to Posts → All Posts. In the list view you should see a small thumbnail column on the left of each post title. All three posts should now show a coloured image — not a grey placeholder box.
    ✅ All three posts have a featured image assigned.
Phase 2 · 45 min

Gutenberg Media — Inline Images

Part 1 of 2
🧱 Featured Image vs Inline Image — What is the difference?
Featured Image
  • Set in the sidebar — NOT inside content
  • The "cover" of the post
  • Shows on homepage cards, social media
  • Only ONE per post
Inline Image
  • Added as an Image block inside the content
  • Appears between paragraphs
  • You can align it, add captions
  • Can have MANY per post/page
  1. Open the About Us page for editing
    1. In the left menu, click Pages → All Pages
    2. Hover over About Us → click Edit
    3. The Gutenberg block editor opens for the About Us page
    Pages → All Pages → Edit (About Us)
  2. Click the area where you want to insert the image
    Click at the end of one of your paragraphs so the cursor is placed there, then press Enter to create a new empty block on the next line.
    💡 The image will be inserted wherever your cursor is. You can always drag blocks up or down with the ⠿ handle on the left side of any block.
  3. ★ KEY STEP Insert an Image block
    There are two ways to add an Image block — try the slash-command method:
    Method 1 — Slash Command (fastest) ⭐ Recommended
    1. On the new empty line, type / (forward slash)
    2. A block search popup appears — type image
    3. Press Enter or click the Image option
    4. The Image block is inserted and you see three options: Upload, Media Library, URL
    Method 2 — Plus Button
    1. Click the + icon that appears in the left margin or top toolbar
    2. Type image in the search box that appears
    3. Click the Image block from the results
  4. Select an image from the Media Library
    1. Inside the Image block, click Media Library
    2. The Media Library popup opens — click one of your uploaded images
    3. A blue checkmark appears on the selected image
    4. Click the blue Select button in the bottom-right corner
    5. The image appears inside the page content
    💡 Do NOT click "Upload" — your images are already in the Media Library. Always pick from there to avoid duplicate files.
  5. ★ KEY STEP Style the image using the block toolbar
    Click on the inserted image. A toolbar appears directly above the image. It has alignment and sizing options:
    ⬅ Align Left
    Image sits on the left, text flows to the right
    ↔ Align Center
    Image centred, full width — text above and below
    ➡ Align Right
    Image sits on the right, text wraps to the left — most professional look
    ↕ Resize handles
    Drag the blue dots on the corners of the selected image to resize it
    Try this: Set the image alignment to Align Right. Your paragraph text will wrap around the left side of the image — this is the most commonly used layout for blog posts.
    💡 You can also add a Caption to your image by clicking the "Write caption…" text that appears directly below the image block.
  6. Update the About Us page to save your changes
    1. Click the blue Update button in the top-right corner
    2. After it saves, click View Page (the link that appears)
    3. You should see the About Us page with your image embedded in the content
    ✅ The About Us page now has an inline image inside its content.

Embedding a YouTube Video — Zero HTML Required!

Part 2 of 2
😓 Week 2 — Raw HTML
<iframe width="560" height="315"
src="https://youtube.com/embed/VIDEO_ID"
frameborder="0" allowfullscreen>
</iframe>

Had to write 5 lines of HTML. Had to find the embed URL. Easy to get wrong.

✅ Week 9 — WordPress CMS
https://www.youtube.com/watch?v=abc123

Just paste the regular URL. WordPress detects it and converts it to a responsive video embed automatically. No HTML needed!

💡 Auto-embed platforms: WordPress auto-embeds content from YouTube · Vimeo · Twitter/X · Instagram · Spotify · SoundCloud · TED · Flickr and 30+ other platforms — always by just pasting the URL.
  1. Go to YouTube and find a tech video
    Open a new browser tab and go to youtube.com. Search for something like "future of technology" or "how computers work" and click on any video.
    Once the video is playing, look at the browser's address bar. The URL will look like this:
    https://www.youtube.com/watch?v=dQw4w9WgXcQ
    💡 Copy the full URL from the address bar, not the "Share" link — both work, but the address bar URL is simpler.
  2. Copy the YouTube URL
    Click inside the browser address bar → press Ctrl+A to select all → press Ctrl+C to copy.
  3. Create a new Post: "My Favourite Tech Video"
    Switch back to WordPress (the other browser tab) and go to:
    Posts → Add New
    1. Click the "Add title" area at the top
    2. Type: My Favourite Tech Video
  4. ★ KEY STEP Paste the YouTube URL directly into the editor
    This is the magic step:
    1. Click below the title to create a new empty paragraph block
    2. Press Ctrl+V (or Cmd+V on Mac) to paste the YouTube URL
    3. You will see the URL text appear for a second, then WordPress automatically detects it is a YouTube link and converts it into a live embedded video player
    1 You paste the URL
    https://www.youtube.com/watch?v=abc123
    ↓
    2 WordPress converts it automatically
    ▶
    Embedded Video Player
    ✅ You should see a video player directly inside the editor — click the preview area to confirm it looks like a video thumbnail, not plain text.
  5. Add a short introduction paragraph before the video
    Click above the video block and press Enter to insert a new paragraph block there, or use the + icon. Type one or two sentences introducing the video:
    "This is a fascinating video about the future of quantum computing that I recommend watching."
  6. Assign a category and set a featured image
    1. In the right sidebar → Categories panel → check Hardware or Software
    2. Uncheck Uncategorized
    3. Scroll down in the sidebar → Featured Image → click Set featured image
    4. Choose one of your uploaded images from the Media Library
    5. Click the blue Set featured image button
  7. Publish the post and preview it
    1. Click Publish → Publish (confirm twice)
    2. Click View Post when the link appears
    3. You should see the embedded video player live on the post page
    4. Click the play button — the video should play directly on your site!
    ✅ You now have 4 posts total — and the latest one has a live embedded YouTube video without writing a single line of HTML.

Permalinks & SEO-Friendly URLs

🔍 What is SEO and why do URLs matter?

SEO = Search Engine Optimisation. It is the practice of making your website appear higher in Google search results. One of Google's most important ranking signals is the URL of a page. Google reads the URL to understand what the page is about.

❌ Default URL (terrible for SEO)
http://localhost/mywebsite/?p=14
  • Google reads ?p=14 — means nothing, zero keywords
  • Cannot rank for any search term
  • Ugly when shared in messages or social media
  • Hard for humans to remember
→
✅ Post Name URL (great for SEO)
localhost/mywebsite/the-future-of-quantum-computing/
  • Google reads keywords: future, quantum, computing
  • Can rank for relevant searches
  • Clean, professional, shareable
  • Auto-generated from the post title
  1. First, check your current ugly URL
    Before fixing it, see the problem yourself:
    1. Click the house icon (top-left admin bar) → Visit Site
    2. Click on any blog post to open it
    3. Look at the URL in your browser address bar
    4. It probably shows something like /?p=14 or /?p=7
    ⚠️ That number after ?p= is WordPress's internal database ID. It means nothing to Google or to humans.
  2. ★ KEY STEP Go to Settings → Permalinks
    Return to the WordPress Dashboard and navigate to:
    Settings → Permalinks
    You will see a list of permalink structure options with radio buttons. Currently "Plain" is selected — this creates the ?p=14 URLs.
    ◉ Plain http://localhost/mywebsite/?p=14 Currently selected — BAD for SEO
    ○ Day and name /mywebsite/2025/01/15/post-name/
    ○ Month and name /mywebsite/2025/01/post-name/
    ○ Post name /mywebsite/the-future-of-quantum-computing/ ← Select this one!
  3. Select "Post name" and save
    1. Click the radio button next to Post name
    2. Scroll to the very bottom of the page
    3. Click the Save Changes button
    4. The page reloads and shows a green success message
  4. Test the new URL format
    1. Click the house icon → Visit Site
    2. If you see a 404 error on the homepage itself, do not panic — see the troubleshooting box below
    3. Click on one of your blog posts
    4. Check the URL in the address bar — it should now show something like:
    http://localhost/mywebsite/the-future-of-quantum-computing/
    ✅ The URL now contains the post title — clean, readable, and SEO-friendly!
🔴 Troubleshooting — "404 Not Found" error after changing Permalinks

Why this happens:

Post-name URLs need Apache's mod_rewrite module to work. This module rewrites the URL path (like /quantum-computing/) into the PHP code WordPress needs to load the right page. On some XAMPP installations it is disabled by default, so Apache does not know how to translate the friendly URL — hence 404.

The Fix — Enable mod_rewrite:

  1. Open the XAMPP Control Panel
  2. Click the Config button next to Apache (NOT the Start/Stop button)
  3. A dropdown opens — click httpd.conf to open it in Notepad
  4. Press Ctrl+F to open Find and search for: #LoadModule rewrite_module
  5. Find the line that looks like:
    #LoadModule rewrite_module modules/mod_rewrite.so
  6. Delete the # at the very beginning of that line so it becomes:
    LoadModule rewrite_module modules/mod_rewrite.so
    💡 The # symbol in config files means "this line is disabled (commented out)". Removing it enables the line. This is exactly like CSS comments!
  7. Press Ctrl+S to save the file and close Notepad
  8. In the XAMPP Control Panel, click Stop next to Apache, then click Start again
  9. Revisit your site — the 404 error should be gone

Site Mini-Audit — Is Your Site Fully Polished?

Go through every item in this checklist. If anything is missing, fix it now before moving to Week 10 (Themes & Plugins).

  • Static Home Page is set
    Settings → Reading → "Your homepage displays" = "A static page" → Homepage = Home. Visiting your site shows the Home page welcome text — not a list of posts.

    Posts → All Posts — count should be 4 or more (3 original + 1 video post), all with "Published" status.
  • Every post has a Category assigned (not Uncategorized)
    In Posts → All Posts, check the Category column — no post should show "Uncategorized".
  • Every post has Tags assigned
    Edit each post and confirm the Tags panel in the right sidebar has at least 2–3 tags.
  • Every post has a Featured Image
    Posts → All Posts — the thumbnail column on the left should show an image for every post, not a grey box.
  • Every image in the Media Library has Alt Text
    Media → Library → click each image and confirm the Alt Text field is filled in.
  • About Us page has an inline image inside the content
    Pages → About Us → click View — there should be an image visible inside the page body, not just text.
  • URLs are using the "Post name" permalink format
    Click any post on your site — the URL in the address bar should read /mywebsite/post-title/ and NOT /?p=14.
  • The YouTube video post plays correctly
    Open the "My Favourite Tech Video" post — the embedded YouTube player should be visible and the video should play when you click it.
