0 / 10 steps

What is SEO?

SEO (Search Engine Optimization) is the practice of making your web pages easy for search engines like Google to understand, index, and rank. No matter how well-designed or functional your site is, it can be completely invisible on Google without proper SEO.

Without SEO

  • Google doesn't know what your page is about
  • Your page ranks on page 5, 6, or doesn't rank at all
  • Almost zero organic (free) visitors arrive
  • Content exists on the web, but no one finds it
→

With Yoast SEO

  • Google understands your topic and target keywords
  • Your page has a real chance to reach Page 1
  • A custom meta description persuades people to click
  • Yoast's coach tells you exactly what to improve
🔗 Week 6 Connection: In Week 6 you wrote <meta name="description" content="..."> in your HTML <head>. The Meta Description you set in Yoast today fills exactly that same HTML tag — Yoast just gives you a friendly form instead of raw code, and makes sure Google uses it properly.

Install & Activate Yoast SEO

Yoast SEO has 5,000,000+ active installations — the most trusted SEO plugin for WordPress. Installation follows the same process as any plugin.

0 / 10 steps

The Navigation Problem

By default, WordPress auto-generates your navigation menu from all pages in alphabetical order — messy, uncontrolled, and unprofessional.

❌ Default Menu (Messy)

About Cart Checkout Contact Home Privacy Policy
  • Alphabetical order — "About" before "Home"!
  • Unwanted pages (Cart, Checkout) show up
  • No categories, no drop-downs possible
  • WordPress decides what appears — not you
→

✅ Custom Menu (Organized)

Home About ▾ Our Story Hardware Software Contact
  • YOU control which items appear and in what order
  • Only the pages you choose are shown
  • Categories can be menu items too
  • Drop-down sub-menus for better organization
💡 How news sites do it: BBC, CNN, and other news sites use category menus exactly like what you are building today. When a visitor clicks "Technology" in their nav, WordPress automatically displays an archive page listing every post tagged as Technology — no extra coding required!

Week 10 — Key Concepts Summary

🎨

Themes → Design

This week:
Session 1 — Astra theme installed, colors & fonts customized
Key idea:
A theme controls only the visual appearance — fonts, layout, colors. It does NOT add features.
🧩

Plugins → Function

This week:
Session 2 — WPForms contact form, Limit Login Attempts security
Key idea:
A plugin is a PHP/JS package that adds features. You can run many plugins simultaneously — unlike themes (only one active).
🔍

SEO → Visibility

This week:
Session 3 — Yoast SEO, keyphrase, meta description, custom menus
Key idea:
SEO tells Google what your content is about so it can rank your pages. The traffic-light system gives instant, actionable feedback.

Quick Reference — Key Terms

Key SEO and menu terms from Session 3
Term What It Is Where in WordPress
Focus Keyphrase The exact search phrase you want your post to rank for on Google Yoast SEO panel → Focus keyphrase field
Meta Description The 1–2 line summary shown under your title in Google results Yoast SEO panel → Edit snippet → Meta description
Snippet Preview A live preview of exactly how your page appears in Google search results Yoast SEO panel → top section
SEO Analysis Red/orange/green dots that rate your on-page optimization against best practices Yoast SEO panel → scroll down
Primary Menu The main navigation bar displayed in your site's header Appearance → Menus → Menu Settings
Drop-down Menu A sub-menu that appears on hover; made by indenting a child item Appearance → Menus → drag item to the right
