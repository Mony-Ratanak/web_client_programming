Before You Start

Make Sure Everything is Running

WordPress needs XAMPP to be running before you can log in. These two checks take 30 seconds and prevent 90% of problems.

  1. Open the XAMPP Control Panel
    Find XAMPP in your Start Menu (Windows) or Applications folder (Mac) and open it.
    Apache Running ● Stop Admin
    MySQL Running ● Stop Admin
    ✅ Both Apache and MySQL must show green text before continuing.
  2. Open your browser and go to the WordPress login page
    Type this URL exactly into your browser address bar:
    http://localhost/mywebsite/wp-admin
    You should see the WordPress login screen. Enter:
    Username: admin Password: 12345
    ⚠️ If you see a white blank page or connection error — XAMPP is not running. Go back to Step 1.
Phase 1

Dashboard Tour & Spring Cleaning

⏱ 30 min

Once logged in, you land on the WordPress Dashboard. The black bar at the top means you are logged in as admin. Let's explore the interface, then delete the dummy placeholder content.

📋 The Left-Hand Menu — What Each Section Does
Dashboard — Site overview, updates, quick stats
Posts — All blog articles. Add New, Categories, Tags
Pages — Static pages like Home, About, Contact
Media — All uploaded images and files
Appearance — Themes, Menus, Widgets
Plugins — Add extra features to the site
Settings — Reading, Permalinks, General info
  1. Visit your site to see it from the front
    In the top-left corner of the black admin bar, hover over the house icon (your site name). A dropdown appears — click "Visit Site".
    W My Class Site ▾ Dashboard Visit Site ← hover here
    💡 The black bar is ONLY visible to you (the admin). Regular visitors never see it. Click the site name again to return to the Dashboard.
  2. Delete the "Hello World!" post
    WordPress creates a dummy post called "Hello world!" by default. Delete it:
    1. In the left menu, click Posts
    2. Hover your mouse over "Hello world!" — a row of links appears below it
    3. Click Trash
    ✅ The post list should now be empty.
  3. Delete the "Sample Page"
    WordPress also creates a dummy page. Remove it:
    1. Click Pages in the left menu
    2. Hover over "Sample Page" → click Trash
    ✅ Pages list should now be empty.
  4. Delete sample comments
    Clear the default comment too:
    1. Click Comments in the left menu (the speech-bubble icon)
    2. Check the box next to any comment to select all
    3. In the "Bulk actions" dropdown → choose Move to Trash → click Apply
Phase 2

Building Static Pages

⏱ 45 min
📄 PAGES — Static Content
  • No publish date — timeless
  • Not in the blog feed
  • Always in the navigation menu
  • Examples: Home · About Us · Contact
📰 POSTS — Dynamic Content
  • Have a date — newest first
  • Appear in the blog feed
  • Organised by Categories & Tags
  • Examples: News · Blog · Articles
📖 Rule of thumb: If content does NOT change often → use a Page. If content is regularly updated → use a Post.
  1. Create the Home page
    Go to Pages → Add New. The Gutenberg block editor opens. Close the welcome dialog if it appears.
    1. Click where it says "Add title" at the top → type: Home
    2. Click below the title → an empty paragraph block appears
    3. Type a welcome message, for example:
      "Welcome to My Class Site. This is a tech news blog about the latest in hardware and software."
    🧱 Gutenberg Block Types you can use:
    /paragraphNormal body text
    /headingH1 to H6 titles
    /imageInsert a photo
    /listBullet or numbered list
    /buttonClickable button
    /quoteHighlighted quote
    💡 Shortcut: Click any empty line and press / to search for any block by name.
  2. Publish the Home page
    When you are happy with the content:
    1. Click the blue Publish button in the top-right corner
    2. A confirmation panel slides in — click Publish again to confirm
    3. Click View Page to preview what visitors will see
    ✅ You should see your Home page live on the site!
  3. Create the "About Us" page
    Click the black WordPress W logo in the very top-left to return to the Dashboard. Then go to Pages → Add New again.
    1. Title: About Us
    2. Add 2–3 paragraphs of dummy text describing the site
    3. Try adding a Heading block (type / then heading) above the paragraphs
    4. Click Publish → Publish
  4. Create the "Contact" page
    Go to Pages → Add New one more time.
    1. Title: Contact
    2. Add a short paragraph: "Use the form below to get in touch."
    3. Click Publish → Publish
    💡 We will add a real contact form later using a Plugin (Week 10). For now, just the page needs to exist.
  5. ★ KEY STEP Set the static front page
    Right now, visiting your site still shows a list of blog posts (or a blank page). We need to tell WordPress to show the Home page instead.
    ❌ Current (Default)
    "Your homepage displays: Latest Posts"
    Shows a blog feed — not good for a business site
    →
    ✅ What We Want
    "Your homepage displays: A static page"
    Shows our Home page content when visitors arrive
    How to change it:
    1. In the left menu go to Settings → Reading
    2. Find the option "Your homepage displays"
    3. Select the radio button "A static page"
    4. Two dropdowns appear:
      • Homepage: select Home from the dropdown
      • Posts page: leave it as — Select — for now
    5. Scroll to the bottom and click Save Changes
    ✅ Click "Visit Site" — you should now see your Home page content, not a list of posts!
Phase 3

Posts, Categories & Tags

⏱ 45 min
🗂️ CATEGORIES — Broad Groups
  • The table of contents of your site
  • A post usually has 1 or 2 categories
  • Must be created before writing posts
  • Today: Hardware & Software
🏷️ TAGS — Specific Keywords
  • The index at the back of a book
  • A post can have many tags
  • Created on-the-fly while writing
  • Today: cpu · tech · future · AI
📰 Newspaper analogy: Categories = Sports · Politics · Business  |  Tags = Messi · World Cup · Barcelona · Transfer
  1. Create the "Hardware" category
    We build the taxonomy before writing posts:
    1. In the left menu click Posts → Categories
    2. In the "Name" field on the left, type: Hardware
    3. The "Slug" field auto-fills — leave it as is
    4. Click the Add New Category button
    ✅ "Hardware" appears in the category list on the right side.
  2. Create the "Software" category
    1. In the "Name" field, type: Software
    2. Click Add New Category
    ✅ You should now see both Hardware and Software in the list.
  3. ★ POST 1 Write the first post — "The Future of Quantum Computing"
    Go to Posts → Add New.
    1. Click the "Add title" area → type: The Future of Quantum Computing
    2. Click below the title → type two paragraphs of content about quantum computing
    Now assign the taxonomy using the right sidebar: (If you cannot see the sidebar, click the gear ⚙️ icon at the top-right)
    1. Find the Categories panel in the right sidebar
    2. Check the box next to Hardware
    3. Uncheck Uncategorized (always remove this)
    4. Find the Tags panel (scroll down in the sidebar)
    5. Type each tag and press Enter or , after each one:
      cpu tech future quantum
    6. Click Publish → Publish
    ✅ Post 1 is live! It should appear in Posts → All Posts with category "Hardware".
  4. ★ POST 2 Write a second post — assign to "Software"
    Go to Posts → Add New.
    1. Title: Top 10 Programming Languages in 2025
    2. Add 2 paragraphs of content
    3. In the right sidebar → Categories → check Software, uncheck Uncategorized
    4. Add tags: python javascript coding
    5. Click Publish → Publish
  5. ★ POST 3 Write a third post — assign to "Hardware"
    Go to Posts → Add New.
    1. Title: The Best Graphics Cards of 2025
    2. Add 2 paragraphs of content
    3. Categories → check Hardware, uncheck Uncategorized
    4. Add tags: gpu gaming nvidia
    5. Click Publish → Publish
    ✅ You now have 3 published posts. Go to Posts → All Posts to verify all three are there.
  6. Verify everything on the front-end
    Click the house icon → "Visit Site". Your site should now show the Home page content (not a list of posts).
    1. You should see your Home page welcome text
    2. The black admin bar should be visible at the top (you are logged in)
    3. Try typing http://localhost/mywebsite/category/hardware/ in the browser — you should see all Hardware posts listed
    💡 WordPress auto-creates archive pages for every category and tag — no extra work needed!
End of Session

Final Checklist — Is Your Site Complete?

Tick every item below. If anything is missing, fix it before moving on to Session 3.

  • Home page is set as the static front page
    Settings → Reading → "A static page" → Homepage = Home
  • 3 pages exist: Home, About Us, Contact
    Pages → All Pages — you should see all three with "Published" status
  • 2 categories exist: Hardware and Software
    Posts → Categories — both should appear in the list
  • 3 published posts — each with a category and tags
    Posts → All Posts — 3 posts, none in "Uncategorized", all have tags
  • No dummy content remains
    No "Hello world!" post, no "Sample Page", no sample comments
  • Visiting the site shows the Home page — not a list of posts
    Click "Visit Site" — you see your Home page welcome content
🎉 Session 2 Complete! You now have a working multi-page WordPress site.
